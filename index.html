Descargar mods

Instalación automatica en Linux (solo PineconeMC)

Descarga el pack de mods en tu carpeta de Descargas y ejecuta este comando en la terminal. Los mods se instalan solos en ElyPrismLauncher (instancia 1.21.1).

curl -fsSL https://a101mdtbb.github.io/cpland/instalar-mods.sh | bash

Para actualizar a una versión nueva y borrar los mods viejos:

curl -fsSL https://a101mdtbb.github.io/cpland/instalar-mods.sh | bash -s -- --limpiar

Video tutorial

Cómo entrar

  1. Instala Fabric 1.21.1Descarga el instalador desde fabricmc.net y crea el perfil para Minecraft Java 1.21.1.
  2. Descarga los modsBaja el pack desde el botón de arriba y pon los archivos .jar en la carpeta .minecraft/mods.
  3. Abre Minecraft con FabricElige el perfil de Fabric en el launcher y pulsa Jugar.
  4. Añade el servidorEn Multijugador, pulsa Añadir servidor y pega rails-complies.tun.ply.gg.
