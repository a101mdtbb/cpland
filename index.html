Cómo entrar

  1. Instala Fabric 1.21.1Descarga el instalador desde fabricmc.net y crea el perfil para Minecraft Java 1.21.1.
  2. Descarga los modsBaja el pack desde el botón de arriba y pon los archivos .jar en la carpeta .minecraft/mods.
  3. Abre Minecraft con FabricElige el perfil de Fabric en el launcher y pulsa Jugar.
  4. Añade el servidorEn Multijugador, pulsa Añadir servidor y pega rails-complies.tun.ply.gg.

      Ayuda rápida

      No puedo conectarme al servidor

      Comprueba que usas Minecraft Java 1.21.1 con Fabric, que tienes los mismos mods que el servidor y que escribiste bien la IP: rails-complies.tun.ply.gg. Revisa arriba si el servidor está en línea.

      ¿Qué versión de Java necesito?

      Minecraft 1.21.1 necesita Java 21. Los launchers modernos, como Prism, lo instalan o lo piden automáticamente.

      Me dice que faltan o sobran mods

      Borra todo lo que haya en tu carpeta mods y vuelve a copiar los .jar del pack. Tienen que ser exactamente los mismos que usa el servidor.

      El juego se cierra al abrir

      Casi siempre es un mod que no corresponde a 1.21.1 o que falta. Reinstala el pack completo y abre el juego con el perfil de Fabric.
